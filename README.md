# LangForge

## 🇺🇸 Overview

LangForge is a language learning platform focused on consistency, daily practice, and structured progression for exams like the JLPT.

It helps users build habits using simple routines, task tracking, and progress analytics.

## 🇧🇷 Visão Geral

LangForge é uma plataforma de aprendizado de idiomas focada em consistência, prática diária e progressão estruturada para exames como o JLPT.

Ajuda o usuário a criar rotina com tarefas, controle de progresso e métricas.

---

## 🚀 Features (MVP)

* User authentication
* Study goal selection (N5–N1)
* Daily task system
* Study tracking (Pomodoro-based)
* Progress tracking
* Streak system

---

## 🧱 Tech Stack

* Backend: NestJS (Node.js)
* Frontend: Next.js (React)
* Database: PostgreSQL
